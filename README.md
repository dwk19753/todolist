# ToDoList

A simple World of Warcraft addon for tracking your daily and weekly to-do items across multiple characters.

## Features

- **Daily To-Dos**: Track daily tasks that reset every day (e.g., World Quests, Mythic+ runs)
- **Weekly To-Dos**: Manage weekly tasks that reset every Tuesday (e.g., Raid Vault, Weekly Dungeon Quest)
- **Character-Specific Tracking**: Each character can maintain their own to-do list
- **Persistent Storage**: Your to-dos are automatically saved and restored when you log in


## Installation

1. Download or clone this addon into your World of Warcraft AddOns directory:
   ```
   World of Warcraft\_retail_\Interface\AddOns\todolist
   ```
2. Restart World of Warcraft or type `/reload` in-game
3. The addon will appear in your AddOns list at character selection

## Usage

Open the ToDoList window and check off tasks as you complete them. Your progress is automatically saved and will reset according to the task type (daily or weekly).
